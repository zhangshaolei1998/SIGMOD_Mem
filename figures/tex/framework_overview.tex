\caption{State, performance, and efficiency occupy separate bands.
Raw sessions retain closed User--Agent conversations; first-order memory
retains query-driven facts; second-order memory retains Agent--Memory
experience. The performance pipeline plans, grounds, and executes,
preserving source support, coverage, and bindings. Cost-aware execution
controls its work through query-specific reservations and selective
refinement. The local blue loop resolves the next bound request.
Dashed paths show state access and feedback; the shared green outer
lane reads and updates action outcomes/cost.}
\Description{The user, agent, and retrieved memory are arranged vertically
on the left. On the right, three aligned memory levels sit above one
left-to-right performance pipeline; an efficiency-control band sits
below. State access descends vertically. A separate horizontal lane
returns retrieved memory to the agent. Closed sessions and use credit
are described inside the raw and second-order state boxes, without
separate agent-feedback arrows. A shared right-hand lane reads and
records action experience. Only dependent binding uses
a local curved return within the performance pipeline.}
\label{fig:framework_overview}
\end{figure*}
