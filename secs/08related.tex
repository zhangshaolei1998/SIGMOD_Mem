\section{Related Work}
\label{sec:related}

\runin{Conversation and fact memory}
MemoryBank models forgetting and reinforcement~\cite{memorybank};
Generative Agents synthesize reflections from stored
observations~\cite{generativeagents}.
MemGPT manages information across context and external memory
tiers~\cite{memgpt}. Mem0 builds persistent memory by extracting and
updating salient conversational facts~\cite{mem0}. Zep represents
time-dependent relationships through a temporal knowledge
graph~\cite{zep}, while A-MEM builds linked notes that evolve with
new experiences~\cite{agenticmem}.

\runin{Learning from memory use}
RMM uses memory citations to update a reranker~\cite{rmm}.
MemRL learns episodic-memory utilities from rewards~\cite{memrl}.
Live-Evo separates an Experience Bank from a Meta-Guideline Bank and
updates experience weights from feedback~\cite{liveevo}.
Our model retains returned and reported-use
fact-version IDs, support diagnostics, and action costs as persistent
operational state. These records guide evidence access and execution
effort across queries; raw sessions and fact provenance establish
source support.

\runin{Retrieval control and memory queries}
HippoRAG supports associative retrieval over a knowledge
graph~\cite{hipporag}; MemoRAG uses global memory to generate retrieval
clues~\cite{memorag}. LongMemEval separates indexing, retrieval, and
reading~\cite{longmemeval}.
MemR$^3$ uses an evidence-gap tracker and a controller that selects
retrieval, reflection, or answering~\cite{memr3}.
LOTUS defines semantic operators~\cite{lotus}; DocETL rewrites document
processing pipelines~\cite{docetl}. LOTUS gives statistical guarantees
relative to a reference algorithm. Our support invariant is defined over
primitive checks and scoped plan execution. Our normalized-plan
partition specifies the required computation; second-order experience
changes evidence priorities, reuse, and budgets across the user's queries.

\runin{Repeated reasoning and computational budgets}
Self-consistency samples multiple reasoning paths and aggregates their
answers~\cite{sc}. Adaptive-Consistency and ESC stop sampling using
accumulated answer agreement~\cite{adaptiveconsistency,escsc}.
Agreement is useful evidence about
variation among outputs, but cannot verify a shared false premise.
EVAPORATE combines extraction with generated code~\cite{evaporate};
QUEST optimizes document-specific extraction~\cite{quest}.
Eddies adapts operator routing at runtime~\cite{eddies}; Bao learns
optimizer hints from execution feedback~\cite{bao}.

Our policy reuses verified values and allocates acquisition or
verification to unresolved predicates, sources, coverage, and dependencies
using historical costs. These decisions use persistent, per-user records
of evidence exposure, reported consumption, and action outcomes.
Additional calls target evidence gaps; an unchanged premise is not resampled.

\section{Conclusion}
\label{sec:conclusion}

\sys{} evolves long-term agent memory in content and use through source
sessions, reusable query-induced facts, Agent--Memory experience, three
query-specific pipelines, and cost-aware execution. Across eight benchmarks, it
matches or improves the strongest evaluated prior system by $2.6$ points on
average. On \membench{}, it reduces memory-side LLM calls by $50.7\%$ while
attaining higher accuracy.
