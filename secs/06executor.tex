\section{For Efficiency: Cost-Aware Execution}
\label{sec:executor}

Plan class determines the required computation, not its expense.
One independent-composition query can reuse every value; another must acquire a
missing property or revisit an ambiguous source. Cost-aware execution
allocates work from the current evidence state and second-order
action experience, then revises that allocation as evidence changes.

\subsection{Query-Specific Budget Allocation}
\label{subsec:new-budget}

An action is a bounded unit of evidence work: acquire a source-backed
property, verify a disputed value, resolve a plan block, or check its result.
Let $\tau(q)$ be the executed action sequence, with $\tau_j(q)$ its
$j$th occurrence. In memory-side LLM calls,
\begin{equation}
\label{eq:cost}
C(q)=C_{\mathrm{plan}}(q)+\sum_{j=1}^{|\tau(q)|}c(\tau_j(q)).
\end{equation}
Each invocation is charged exactly once, including repeated actions.
Semantic synthesis or validation by $g$ is an execution action, not free finalization.
Acquisition and verification are not free write-path
overheads. Deterministic reads, selection, and arithmetic use zero
LLM calls but can still incur latency. Agent-side query formulation
and final answer generation are accounted for separately in an
end-to-end ledger.

The executor maintains evidence obligations for scope coverage, values,
versions, bindings, and result checks.
For the current snapshot of instantiated obligations $\Omega$, let
$\ell(\Omega)$ be the unresolved fraction, with $\ell(\varnothing)=0$;
conflicts leave a check
unresolved. It is an observable evidence-gap diagnostic, not online
accuracy or a calibrated error probability.
Neither agreement nor an empty diagnostic after failed plan compilation
certifies a result. Ambiguous compilation remains an unresolved check.

An action's observed reduction compares the same pre-action set:
$\Delta\ell(a)=\ell_{\mathrm{before}}(\Omega)-
\ell_{\mathrm{after}}(\Omega)$.
Newly discovered candidates add obligations to the next decision's
snapshot, not to this comparison's denominator.
Thus useful scope discovery is not penalized merely for exposing
additional work. The executor then checks the expanded set before
certifying a result or allocating the next action.

For each executed action, $\Uu$ stores its context, obligation snapshot,
observed reduction, and actual call cost. A context signature contains action
kind, plan class, unresolved-check types, candidate count, dependency
depth, and cache availability (all, some, or none). To estimate an available action's
diagnostic reduction $\widehat{\Delta\ell}(a)$ and cost $\widehat c(a)$,
the executor averages matched historical reductions and costs with one
declared prior observation. Detailed signatures match these fields exactly.
It backs off from the detailed signature
to the same user's action-kind/plan-class history, then to the prior.
Matching and backoff use these declared fields and order.
These are predictions from executed actions, not counterfactual labels.

The cold prior supplies the template's declared call count and half
the fraction of unresolved checks it could discharge with available
sources, or zero when none is available. This is an initial assumption,
not a measured success rate; its weight decreases with matched experience.
Each action declares an enforced maximum reservation $c_{\max}(a)$:
$0\leq c(a)\leq c_{\max}(a)$, distinct from its predicted mean cost.
An action that reaches its reservation returns its current evidence state.

From dependency-ready actions, the executor constructs a worklist
$\mathcal A_+(q)$ in descending predicted net benefit
$\widehat{\Delta\ell}(a)-\lambda\widehat c(a)$.
Only positive-benefit actions that fit the remaining hard cap are admitted.
The current additional-call budget is
\begin{equation}
\label{eq:new-adaptive-budget}
K(q)=\sum_{a\in\mathcal A_+(q)}c_{\max}(a)
\ \leq\ K_{\max}(q)-C_{\mathrm{spent}}(q).
\end{equation}
Here finite $K_{\max}(q)\geq0$ caps all memory-side calls, including planning, and
$C_{\mathrm{spent}}$ records calls already paid.
Planning is invoked only under a reservation that fits the cap; otherwise
the system reports the unresolved plan rather than overspending.
$\lambda\geq0$ prices diagnostic reduction against calls.
The worklist, $C_{\mathrm{spent}}(q)$, and $K(q)$ refer to the current
decision, not fixed query-wide constants. After each action, unused reservations are released
and the worklist is rebuilt from the new evidence state.

\subsection{Selective Refinement and Experience Feedback}
\label{subsec:new-value}

When admissible actions exist, the next action maximizes predicted net benefit:
\begin{equation}
\label{eq:short}
\begin{aligned}
a^*&\in\argmax_{a\ \mathrm{admissible}}
 \{\widehat{\Delta\ell}(a)-\lambda\widehat c(a)\},\\
\mathrm{continue}&\ \Longleftrightarrow\
 \widehat{\Delta\ell}(a^*)>\lambda\widehat c(a^*).
\end{aligned}
\end{equation}
If no action is admissible, execution stops.
Admissibility requires available inputs and a reservation that fits
the remaining cap. A prerequisite sequence with delayed benefit can
be evaluated as one bounded bundle, charging every invocation within it.
A bundle's first action must be ready, with later inputs supplied by
earlier actions in the bundle. The rule is a local, experience-based decision, not a claim of globally
optimal scheduling or guaranteed accuracy improvement.
Free deterministic work is not repeated on unchanged inputs.
Repeated semantic judgments consume calls from the hard cap.
With a finite plan and source snapshot, these rules prevent an
unresolved gap from inducing an unlimited retry loop.

Execution reuses verified subresults and spends only on unresolved
work. Semantic disagreement can trigger another judgment; shared
unsupported evidence calls for source acquisition instead of voting.
If an input changes, only its dependent descendants are invalidated
and recomputed. Exhausting the cap or declining further work does not
convert a gap into a supported result: $\sigma$ remains partial or
unknown as appropriate.

\begin{memoryexample}{Example 3: reuse completed work, resolve the new gap}
\textbf{Warm query.} Alice again compares the outdoor activities.
Reuse verified settings and durations: $4>3$, with $K(q)=0$ additional
memory-side calls. Agent answer generation is separate.

\smallskip
\textbf{New gap.} A closed March 23 session says,
\emph{We planned an outdoor picnic, but rain changed our plans.}
Its follow-up says, \emph{We ate inside River Cafe instead.}
The two descriptions refer to one outing, not two activities.
Alice's March 24 count needs its actual occurrence and setting,
not merely the planned picnic.

\smallskip
\textbf{Selective action.} Verify the outing and acquire its actual setting when
predicted benefit exceeds cost, charging extraction/verification calls.
Reuse the three earlier judgments; update only the new outing:
$1+0+1+0=2$.

\smallskip
\textbf{Unavailable evidence.} Without the follow-up, the closed
four-candidate scope supports $[2,3]$, not an exact count.
Repeating the planned-picnic fragment cannot resolve this gap.
\end{memoryexample}

Query totals $C(q)$, action outcomes, and diagnostic changes update
$\Uu$ independently of whether the agent supplies a use report.
Validated reported use updates the
fact-priority statistics in Section~\ref{subsec:new-experience}.
The records distinguish cold acquisition from warm reuse and guide the
next query's priorities and budget. Acquired facts evolve content;
remembered use, outcomes, and cost evolve memory operations.
