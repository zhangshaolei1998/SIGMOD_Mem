\begin{abstract}
Long-term LLM agents need memory that evolves both its content and its
operations. We introduce \sys{}, a continually evolving memory management
system with three levels. Raw sessions accumulate closed User--Agent
conversations. First-order memory acquires source-backed user facts on
demand. Second-order memory retains Agent--Memory experience: returned
evidence, validated use credit, and execution outcomes/cost. First-order
facts help the agent understand the user; second-order experience helps
memory understand how to serve the user. For performance, single-fact
retrieval, independent composition, and dependent composition partition
normalized finite acyclic evidence plans and execute with
experience-guided grounding. For efficiency, current evidence gaps and
historical action outcomes determine a query-specific call reservation
and whether further work is worthwhile. Unmet evidence obligations
remain explicit when execution stops. The prototype evaluation covers
eight long-term memory benchmarks. Its reported scores match or improve
the strongest evaluated prior memory system on every benchmark, by an
average of $2.6$ points and up to $5.6$ points on \lmes{}.
On \membench{}, the reported configuration uses $50.7\%$ fewer read-path
LLM calls than a Uniform-$K{=}3$ reference while attaining higher accuracy.
These measurements test prototype evidence processing, workload-guided
access, and selective execution; finer routing, fact-version credit,
and action-value forecasts require targeted evaluation.
\end{abstract}
